Complete block reference (16 blocks)

Structured Data

Named structured data with safe JSON/YAML codecs and deterministic path operations.

Blocks

Parse JSON or YAML into a target-local name, update it with restricted paths, iterate with an explicit bound, and render it back to JSON or YAML.

Enable the MVP

Set globalThis.STRUCTURED_DATA_MVP = true in the TurboWarp page, then load structured-data.js with Run extension without sandbox enabled. Start with parse JSON ... as ... or parse YAML ... as ....

Development

See the repository README and architecture documentation for build, test, release, and compatibility details.

for each in [NAME] at path [PATH] max [MAX]

Iterate named data deterministically with a static maximum.

Block type: LOOP. Opcode: forEachAtPath. Permanent link

ArgumentTypeDefault valueMenu choices
NAMESTRINGdata
PATHSTRING$
MAXNUMBER100

MVP機能を有効にした場合だけ、MAXを整数1〜1000で編集します。入力途中・空白・非finiteな新値は保存できません。NAMEとPATHは変更しません。 GUIのDialogsとFixedInputsは起動時の既定OFFです。両方を有効にして再読込すると固定フォームが使えます。未変更のraw値を保存し直さず、接続reporterは評価しません。
