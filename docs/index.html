Structured Data

Named structured data with safe JSON/YAML codecs and deterministic path operations.

Blocks

Parse JSON or YAML into a target-local name, update it with restricted paths, iterate with an explicit bound, and render it back to JSON or YAML.

Enable the MVP

Set globalThis.STRUCTURED_DATA_MVP = true in the TurboWarp page, then load structured-data.js with Run extension without sandbox enabled. Start with parse JSON ... as ... or parse YAML ... as ....
